## 已验证范围

- 存活检查、真实数据库连接检查。
- USER、AGENT、ADMIN 登录；错误密码、缺失/无效 JWT 返回 401。
- 工单创建默认值及创建人来自认证信息；伪造创建人和修改受保护字段被拒绝。
- 详情、分页、筛选、自己的工单；普通用户、客服、管理员的数据范围隔离。
- 参数、枚举、工单 ID、分页边界和标题长度校验。
- 修改内容后版本递增、旧分类重置；旧版本及已分配工单修改返回 409。
- 真实 MySQL 并发修改同一版本：一个请求成功，一个返回 409；版本只增加一次。
- CREATE 历史记录落库，只有成功的修改产生 UPDATE 历史。
- 禁用账号或移除角色后，已有 JWT 被拒绝。
- H2 自动化测试额外覆盖事务回滚及数据库分页 SQL 等行为。
