# 智能工单管理系统

当前阶段：后端基础工程、最小登录/JWT、基础工单管理、分配、状态流转、AI 分类，以及前端基础工程。

启动、验证、文件说明和排错步骤见 [backend/README.md](backend/README.md)。

前端启动、环境变量、路由和 Axios 说明见 [frontend/README.md](frontend/README.md)。

本阶段迁移、接口、权限和测试见 [基础工单接口文档](backend/docs/ticket-api.md)。
